# RAIA.VISION portfolio

Static site (no build step), hosted free on GitHub Pages.

## Add or swap a video
1. Export a web version: MP4 (H.264/AAC), 720x1280 for vertical or 1280x720 for horizontal, under about 20 MB.
2. Put it in `media/<slug>.mp4` and a poster frame in `posters/<slug>.jpg`.
3. Add or edit its entry in `assets/projects.js`.
4. Commit and push. The site updates in about a minute.

GitHub limits: 100 MB per file, about 1 GB per site.
